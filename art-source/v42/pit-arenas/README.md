# Fonds originaux des arènes 21–100

80 PNG acceptés, créés avec l’outil intégré image_gen.imagegen. Les fichiers publics sont des copies octet pour octet des originaux ; aucun repeint, détourage automatique, coloris de substitution ou génération locale n’a remplacé les sorties OpenAI.

Chaque dossier conserve le prompt réellement envoyé, le chemin source original, le SHA-256, les dimensions, l’acceptation visuelle et la référence à la copie archivée. La revue P0 ne valide pas automatiquement l’assemblage runtime : les preuves de composition et d’application sont distinctes.

Les premières tentatives 28–30 ont été rejetées pour architecture fantasy/humaine inadéquate, puis régénérées. Les sorties rejetées restent conservées localement et ne font pas partie des 80 images livrées. Les modules des anciens kits restent dans leur bibliothèque d’origine ; aucun doublon de PNG n’est créé pour gonfler les comptes.

composition-plan.json décrit l’assemblage et ses limites. Les prompts effectifs de référence sont ceux des reçus receipt-p0-depth.json, certains ayant été précisés après l’établissement du plan initial.
