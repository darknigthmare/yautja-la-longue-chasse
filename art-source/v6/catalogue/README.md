# Source du catalogue Yautja V6

`catalogue_yautja_tous_medias.xlsx` est la copie binaire immuable du classeur
fourni pour la mise à jour. L’application utilise l’onglet `Index maître`.

- taille : 62 111 octets ;
- SHA-256 : `6b696cabe94f0821f4bc02a1587ca5782789ffcc58ad52339626cc173515e68e` ;
- extraction runtime : `app/game/catalogueRoster.ts` ;
- contrôle de provenance : `tests/catalogue-roster.test.mjs`.

Le classeur contient 255 entrées. Une ligne de catalogue n’est pas assimilée à
une plaque visuelle exacte : les entrées sans preset de production conservent
un avertissement de reconstruction et affichent séparément la source de leur
fiche et les sources de la famille visuelle utilisée comme base.
