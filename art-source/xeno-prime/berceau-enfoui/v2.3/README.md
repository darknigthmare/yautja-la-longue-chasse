# Xeno Prime — Le Berceau enfoui · sources PNG V2.3

Ce dossier contient les **150 sprites individuels et six fonds** du pack V2.3, ajoutés à la PR de la bible à la demande de l’utilisateur. Les **156 PNG sont conservés à l’octet près**, sans redimensionnement, recompression ou modification de l’alpha. Les identifiants 001–108, A001–A042 et BG01–BG06 sont conservés.

Pour consulter la galerie et le lecteur, récupérer le dossier avec ses sous-dossiers puis ouvrir les fichiers HTML. Les chemins relatifs du pack restent valides. Les 76 fichiers de consultation et de provenance du pack livré sont eux aussi conservés à l’identique ; ce README et l’index Markdown facilitent la navigation dans GitHub.

Ces fichiers constituent les sources graphiques du secteur. Les animations fluides, les pivots et attaches, les collisions et les comportements restent à intégrer dans le moteur. Les indicateurs de validation artistique humaine et de qualification en jeu restent à `false`. Les anciennes compositions V2.1 gardent leurs 312 placements et leur statut historique.
