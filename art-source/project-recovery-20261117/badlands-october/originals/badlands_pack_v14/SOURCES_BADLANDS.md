- https://theyard-vfx.com/title-item/predator-badlands/

**Notes de fidélité**

- Désignation descriptive. Le nom de fichier officiel design_cafard sert à identifier le petit arthropode, sans prétendre que « cafard » est un nom canonique d’espèce.
