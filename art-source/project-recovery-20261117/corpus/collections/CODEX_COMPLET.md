# THE PREDATOR — CHASSE CROISÉE · Codex complet v0.2
Ce codex documente la transposition du montage cinéma 2018 dans le DLC. Les formulations sont originales et servent de contrat de gameplay ; elles ne reproduisent pas le script du film.
## Règles de fidélité
- La campagne principale suit exclusivement le montage cinéma 2018 sorti en salles.
- Les événements sont reproduits dans leur ordre narratif, mais aucun dialogue du film n’est retranscrit mot pour mot.
- Le Fugitive reste jouable jusqu’à sa mort canonique ; la campagne Predator bascule ensuite sur l’Upgrade.
- Les Emissary Predators, l’APC et la ménagerie d’hybrides supprimés sont exclus de la campagne principale.
- Le Predator Killer est conservé comme épilogue du montage cinéma.
- Les graphismes du prototype sont des interprétations originales ; les images officielles ne sont pas redistribuées.
- Les trois décors V43 déjà présents dans La Longue Chasse sont utilisés seulement quand le DLC est installé dans le projet hôte.
