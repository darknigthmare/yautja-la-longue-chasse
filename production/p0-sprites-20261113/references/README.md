# Recherche des références

Les deux rapports JSON sont des copies inchangées des recherches du 13 novembre
2026. Les URL, commits et empreintes identifient les sources consultées. Les DDS
communautaires et leurs captures de diagnostic ne sont pas distribués avec le lot.

- `reference-research.json` : six fronts de masques exploitables comme références
  secondaires. Les trois icônes de coques sont adaptées à un squelette humain par
  le port communautaire et ne permettent pas de reconstruire les proportions PHG.
- `research-addendum.json` : recherches complémentaires sans nouvelle référence
  de forme pour City Rebreather, Haze, Rival, Saber et Tank. Les noms ressemblants
  ne sont pas assimilés à ces modèles sans preuve.

Les téléchargements officiels essayés ont reçu un refus CONNECT 403, sans contenu
image. Le statut observé du réseau n'établissait pas quelle règle avait causé le
refus. Une proposition limitée aux hôtes officiels nécessaires a été enregistrée
dans la configuration de l'environnement ; elle exige encore l'enregistrement et
la publication par l'utilisateur dans les paramètres de l'environnement. Elle
n'est pas considérée comme appliquée.

Les images de face communautaires peuvent guider la silhouette, sans établir les
couleurs d'origine, les vues profil/dos ou la conformité des UV. Les masques
produits restent des candidats et les coques Alpha/Samurai n'ont pas été
reconstruites à partir de proportions humaines.
