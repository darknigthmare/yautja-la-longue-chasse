Les trois titres et objectifs affichés correspondent aux fichiers ; la version V120 d’origine reste dans le volet historique et sous `original` dans le JSON. Les 30 réponses JavaScript Next correspondent aux fichiers du build ; les six sources surveillées et le BUILD_ID sont identiques avant et après. Aucune erreur JavaScript, console, HTTP ou requête n’a été observée. Les quatre PNG originaux ont été ouverts ; [leur inspection](screenshot-inspection.json) reste distincte d’une validation artistique humaine.
