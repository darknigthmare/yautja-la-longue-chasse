# The PIT — traçabilité des 68 rubriques du guide

**Audit documentaire du 27 novembre 2026**, sur la base et les ajouts de la branche décrits dans le [premier point de reprise](CONTINUATION_20261127.md) et le [lot 2](CONTINUATION_20261127_LOT2.md).

Toutes les sources sont présentes dans [combat-guide](combat-guide/README.md). Les statuts ci-dessous décrivent la correspondance avec le projet, pas une certification de toutes les exigences individuelles. La checklist des extensions conserve 172 critères et 40 cas d’acceptation.

**P0** : intégration actuelle et contrats fondamentaux. **P1** : prochain contenu cohérent et fonctionnalités demandées. **P2** : dépendances plus larges, monde explorable ou services. « Conçu » et « différé » n’annoncent aucun runtime livré.

## Lecture des preuves

L’inventaire runtime est un comptage de modules évalués. Les références de tests décrivent les suites pertinentes ; le [point de reprise](CONTINUATION_20261127.md) donne les exécutions réellement obtenues. Les captures et revues artistiques gardent leur périmètre exact. Un import documentaire ne ferme pas une ligne de production artistique et une réussite de tests logiques ne valide pas un parcours réseau ou un abonnement non créé.
