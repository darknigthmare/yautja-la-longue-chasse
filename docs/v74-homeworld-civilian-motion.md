# Populace V74 : fonctionnelle, finition artistique partielle

Le renderer utilise 112 poses PNG OpenAI réellement dessinées : quatre à droite et quatre à gauche pour les quatorze costumes civils V72. Les huit sources actives sont des copies byte pour byte des sorties natives. Les 128 fenêtres de ces sources ont été mesurées ; aucun pixel alpha supérieur à12 ne touche une limite de découpe. Aucun PNG V72 n’a été modifié ni supprimé.

Les 98 habitants gardent leurs trajets, professions, dialogues, vitesse et phaseSeconds. Le clip reçoit `seconds + resident.phaseSeconds` depuis l’horloge de ville, tandis que le calcul de trajet reçoit toujours `seconds` seul. La cadence suit leur vitesse actuelle. Aucun minuteur CSS indépendant, oscillation factice, nouveau collider ou miroir de marche n’a été ajouté. La projection du sol, les pieds et le culling restent ceux de la population existante. Une seule échelle est utilisée par rôle, sans étirement selon les contours de chaque pose. À l’arrêt et pour les personnages nommés, le portrait V72 reste utilisé par défaut.

Statut : **functional PASS / PARTIAL_ART**. Les poses bougent réellement, mais plusieurs boucles montrent encore le même genou apparent dans les deux passages. L’alternance physique jambe proche/jambe éloignée n’est pas artistiquement certifiée pour tous les rôles. Les 112 fenêtres différentes et leurs hashes vérifient les sources ; ils ne prouvent pas à eux seuls un bon cycle anatomique. Ce lot ne doit pas être présenté comme quatorze animations commerciales finalisées.

Les itérations natives ont été conservées dans `work-local/v74/native-diagnostics` et `work-local/v74/pose-reference`. Elles incluent les poses initiales, les gouttières insuffisantes, les mauvaises directions, les essais de couleurs et les références d’appui. Le dernier essai d’artisane à greave repérée rend son alternance plus claire, mais il reste un diagnostic non intégré au lot de huit sources figé. Aucun guide de couleur ni essai rejeté ne figure dans le répertoire public final.

Références de locomotion uniquement : [Animation Mentor](https://www.animationmentor.com/blog/tutorial-animating-human-walk-cycle/), [Monmouth University](https://animation.monmouth.edu/instruct/animation/walk-cycle/) et [George Maestri / SIGGRAPH](https://education.siggraph.org/static/HyperGraph/animation/character_animation/walking/learning_to_walk.htm). Elles servent aux contacts, passages, contrebalancement et vitesse des pieds ; elles ne définissent pas le lore Yautja. Les costumes civils et le chef local sont des adaptations originales du projet, sans affirmation d’une monarchie universelle canonique.

Les cinq tests motion et six régressions identité ont passé ; TypeScript a passé. La prévisualisation du composant réel a été inspectée dans Edge aux quatre phases, sur les deux directions et les quatorze rôles, sans erreur console.

La recette locale finale du 2 octobre 2026 à 09:09 UTC a passé **14 contrôles**, avec **4 captures**, sur `http://127.0.0.1:4192`. Le script `scripts/verify-homeworld-civilian-motion-v74.mjs` produit le tableau des 112 poses du composant réel, vérifie HTTP200 et SHA256 des huit sources, puis relève les 98 trajets existants sur cinq instants (490 poses de modèle). Dans la ville réelle, le premier pas fonctionne après le préchargement intégré sans décodage manuel ; 40 échantillons montrent quatre habitants visibles et 25 poses en mouvement. La pause publique fige pendant deux secondes le temps, les positions et les fenêtres natives. En portrait 393×852, le déplacement fonctionne, deux habitants restent visibles et la page ne déborde pas horizontalement. Aucune erreur de page ni réponse HTTP en échec n’a été observée.

Les preuves sont dans `work-local/v74/qa/civilian-motion-local/report.json`, avec le tableau des poses, les métadonnées des 98 trajets, les échantillons de ville et les quatre images. Le rapport archivé est `docs/v74-homeworld-civilian-motion-qa-local.json`. Ces contrôles passent fonctionnellement, mais ne certifient pas l’anatomie des quatorze boucles, ne prétendent pas montrer 98 habitants simultanément et ne prouvent pas encore une publication : les preuves publiques restent distinctes.
