# Interstices visuels du passage des marais — diagnostic restant

Les captures originales R5 et R6 `life-marsh-watch-native-grounded.png` montrent les mêmes fines bandes sombres. Une session exploratoire distincte sur le build R6 `vxOXqmuKalwQbkLqTZnwN` les reproduit depuis un checkpoint déclaré; elle n'atteste pas une nouvelle marche ni un parcours complet. Les six captures exploratoires conservées ici ont été réellement ouvertes. Aucune image, géométrie, source app ou coordonnée d'objet n'a été modifiée.

Le premier calcul utilisait par erreur le zoom général 0,96. La caméra extérieure active emploie 0,9. Avec les matrices DOM réelles, le pixel (414,400) devient environ (6133,2414,51) dans le monde; (414,750) devient (6133,3092,52), et (882,540) devient (6653,2685,71). À ces points précis, aucun polygone public ne contient le point. Les sondages précédents x6140…6170 portaient sur le voisin effectivement supporté par `rampart-low-causeway:2`. À droite, `port-marches-road:1` s'arrête à x6650; son voisinage intérieur reste supporté. `exact-ground-probes.json` garde chaque mesure et ses IDs.

Le problème observé correspond donc à de petits interstices extérieurs entre les contours pavés conservés, où la composition native sous-jacente devient visible. Ce diagnostic n'annonce pas un trou physique au milieu du chemin parcouru par le guetteur. Le parcours canonique de cette voie reste une preuve distincte du présent examen.

Les interventions temporaires du navigateur attribuent le rendu sans le corriger : masquer les fondations V81 change zéro pixel dans les trois régions mesurées; masquer la couche naturelle V112 change les bandes de gauche; masquer les écotones change une partie de celle de droite. Le sommet naturel `v71:rampart-walk` occupe aussi cette zone extérieure au masque public. Retirer le filtre du pavement modifie son rendu plus largement et ne résout pas la bande basse. Les valeurs brutes figurent dans `pixel-comparison.json`; les SVG et leurs IDs figurent dans les traces DOM.

**État restant : composition de rive à reprendre.** Aucun correctif minimal de rendu n'est qualifié et aucun patch app n'est proposé. Le contributeur exact dans l'ensemble des motifs/masques naturels n'est pas encore réduit à une seule primitive. Une reprise devra traiter la limite comme une composition explicite, sans maquiller un espace non praticable par du pavement ni supprimer une falaise réelle. Les PNG natifs ouverts, dont le pavement civique et la fondation basaltique, restent intacts; leurs pins sont conservés dans `report.json`.

Le premier lancement du diagnostic attendait à tort la visibilité d'un ancrage DOM de taille nulle. Son timeout est conservé dans `initial-zero-size-anchor-selector-failed.log`; le pilote exploratoire corrigé attend seulement sa présence. Ce défaut du diagnostic n'est pas une erreur de l'application. Le pilote conservé utilise les chemins locaux de cette session; ses changements de visibilité/filtre sont explicitement exploratoires et ne servent jamais à certifier le produit.
