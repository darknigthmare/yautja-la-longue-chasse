# Portraits et créatures récents — sources V85, fidélité non certifiée

Le dossier Drive `1knnlhc3gNyz6MRSDKqbya5I9cBD92m-t` a fourni une liste de 131 fichiers directs. La collecte est volontairement limitée aux sept PNG nommés demandés, tous créés dans Drive le 7 octobre 2026 : cinq références de xénomorphes Kenner (Rhino bleu et orange, Snake série 13, Panther et Night Cougar), puis deux profils du même Yautja Wolf 2007, masqué et sans masque. Ce lot ne représente pas sept nouveaux chasseurs.

Les références officielles NECA documentent [Rhino Alien (Kenner Tribute)](https://necaonline.com/2020/04/alien-ultimate-big-chap-kenner-homage-drake-rhino-and-ultimate-annabelle-from-the-conjuring-universe/), [Snake Alien dans Aliens série 13](https://store.necaonline.com/blogs/news/shipping-this-week-aliens-series-13-godzilla-1963), [Panther Alien](https://store.necaonline.com/products/aliens-7-scale-action-figure-ultimate-kenner-tribute-panther-alien) et [Night Cougar Alien](https://store.necaonline.com/products/aliens-7-scale-action-figure-ultimate-kenner-tribute-night-cougar-alien). La famille des cinq PNG concorde avec leur apparence de créatures ; cela ne certifie ni leur moule, ni leurs couleurs, ni une fidélité graphique 1:1. Snake Alien série 13 ne doit pas être confondu avec Snake Predator. [Wolf est un Predator d’AVP: Requiem](https://store.necaonline.com/blogs/news/174261575-the-nearly-invisible-killer).

Les sept fichiers sont conservés avec leurs pixels inchangés, leur SHA-256, leurs dimensions PNG, leurs dates et leurs identifiants Drive. Ils totalisent 14 132 192 octets. La déduplication avec les registres antérieurs — 1 396 PNG uniques locaux, 54 fichiers Drive récents et 41 ajouts Badlands — n’a trouvé aucun doublon : sept nouveaux PNG sont persistés dans `/game/imports/v85/drive-latest/approved-hunters/`.

Le registre dédié `app/game/data/recentApprovedHuntersV85.json` rejoint le provider `recentSpriteLibraryV85.ts`. Le codex et la galerie consomment cette union. Le pack porte le libellé neutre « Portraits et créatures · sources récentes » et distingue « Xénomorphes Kenner · références statiques » (`fauna`, cinq images) de « Wolf · références Yautja » (`npc`, deux images). Le provider Yautja exclut les cinq créatures, même par identifiant explicite ou avec les versions historiques. Les sept références restent des poses statiques distinctes : aucune série de frames, tenue de marche remplacée, compétence, statistique, récompense, ennemi ou combattant jouable n’est créé. Les deux profils Wolf et les deux couleurs Rhino conservent leurs IDs et identités source séparés. `sourceLabel` conserve les anciens libellés ; les deux Wolf partagent seulement le sujet canonique général.

« Validé » désigne uniquement le classement dans le dossier source. Le statut `provided-approved-folder-native-unverified` reste inchangé ; la classification d’espèce ne certifie pas les pixels. Les autres images du même dossier, ainsi que le dossier d’essais/rejets, restent exclues. Aucune couverture exhaustive des PNG Drive des trois derniers jours n’est revendiquée ; les 640 variantes PNJ V84 restent des métadonnées sans pixels dans l’archive locale fournie.

Les copies originales et le fichier de métadonnées restent en staging privé `.work-local/recent-approved-hunters-v85/`. La provenance logique est dans `docs/recent-approved-hunters-v85-sources.json` ; l’ancien périmètre descriptif est conservé sous `sourceScope`. Aucun script fourni dans une source n’a été exécuté. L’import initial n’avait pas de QA : ses indicateurs historiques restent conservés. Le test ciblé `tests/recent-source-species-v85.test.mjs` vérifie désormais les familles, les vrais SHA/dimensions PNG et le filtrage du provider. Cette correction ne constitue pas une validation navigateur ou de fidélité visuelle ; la publication relève du lot principal autorisé.
