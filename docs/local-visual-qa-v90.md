# Route locale de composition V90

`/visual-qa-v90` est un outil de QA synthétique, pas une campagne ni une reprise de sauvegarde. Le serveur exige exactement `YAUTJA_LOCAL_VISUAL_QA_V90=1` dans son processus local et refuse aussi `VERCEL=1`. Sans cette variable, le proxy renvoie directement une réponse 404 avant le rendu de l’application ; la page conserve en défense le même gate `notFound()`. Aucun paramètre d’URL, cookie, état navigateur ou donnée de campagne ne peut activer la route. Le flag n’est ni public, ni inscrit dans une configuration ou un fichier `.env` du dépôt.

Le segment exporte `dynamic='force-dynamic'`, option du guide installé « Caching without Cache Components » et du runtime vinext ; `cacheComponents` n’est pas activé dans ce projet. Le flag est ainsi relu à chaque requête et non figé pendant le build. La page reste synchrone : son refus précède tout JSX. La variante avec `await connection()` et la variante synchrone sans proxy ont toutes deux produit un **HTTP 200 contenant le NotFound streamé**, sans scène QA, lors des contrôles HTTP réels (`work-local/v90/qa/local-gate-http-final.json` pour le second). Le layout streamé rend ce contrôle de contenu insuffisant pour certifier le statut HTTP.

`proxy.ts` ajoute maintenant une réponse directe `NextResponse('Not found', {status:404})`, avec `Cache-Control: private, no-store` et `X-Robots-Tag: noindex, nofollow`. Son matcher littéral `/visual-qa-v90/:path*` est testé par l’utilitaire réellement exporté dans ce paquet, `unstable_doesMiddlewareMatch` (`unstable_doesProxyMatch` est le nom du guide, absent du module chargé) ; les menus, API et assets ne sont pas interceptés. Les dix tests emploient de vrais `NextRequest` et `NextResponse`, sans imitation de leur statut ou de leurs headers. Après le build final, le **transport HTTP 404 est confirmé** sans flag, avec un paramètre d’URL tentant d’activer le flag et sur un sous-chemin ; le menu répond toujours 200. Preuve privée : `work-local/v90/qa/local-gate-http-proxy-final.json`. Ce contrôle local ne certifie pas le déploiement public.

Après avoir lancé un serveur local avec ce flag uniquement dans son environnement, ouvrir `/visual-qa-v90`. Choisir une des sept entrées régionales ou un des quatre écotones de plateau déjà admis par `HOMEWORLD_ECOTONES_V90`. Leur identifiant, ancre, arrivée et étage sont lus depuis les vrais modèles V90 ; aucun candidat refusé ni seuil inventé n’est ajouté.

Le client monte directement **HomeworldWorldSceneV77**, avec ses sols, ses masques, ses sprites, sa population et ses modules natifs. Le cadrage suit la même fonction `homeworldCameraWorldV77` et la même projection que le Hub. Le panorama réduit uniquement le zoom de la vue d’observation. Les boutons déplacent la caméra, le curseur choisit un instant des routines existantes, et l’étage peut être changé pour observer la pile de décors. Une position modèle peut être non admise sur un autre étage **ou à l’ancre décorative d’un écotone de plateau** : l’UI l’indique explicitement. Pour ces plateaux, `arrival` reprend l’ancre d’une formation V85 render-only ; ce nom de champ n’en fait pas une arrivée de joueur, un spawn ou un nouveau sol physique. Le cadrage `south-alluvium` observé au niveau natif signale ainsi une position non admise, sans modifier la physique.

Toutes les commandes restent en état React local. Aucun import de campagne, initialisation de sauvegarde, verrou, stockage, XP, mission, accès régional ou récompense n’est demandé. Le repère de position facultatif est une annotation synthétique, pas un avatar jouable. Les instantanés n’établissent pas une animation jouée en continu.

Les captures de cette route peuvent étayer la composition, la perspective et la présence des pixels du renderer réel. Elles **ne prouvent pas** la traversabilité, les intérieurs, les droits d’accès, les trajets, la sauvegarde ou le fonctionnement d’une campagne. Les scènes restent des adaptations originales du plateau volcanique ; elles ne constituent pas une reconstitution canonique 1:1 de Yautja Prime.

La capture locale `work-local/v90/qa/homeworld-pillars-synthetic.jpg` a été inspectée : bannière synthétique, Passerelle des Piliers, arrivée modèle `(2900,250)`, étage natif `0`, panorama `×0,45`, sols et props natifs visibles. Elle étaye uniquement ce cadrage de l’observateur. Les autres vues de côte, grottes thermiques et alluvions sud rapportées par l’agent principal restent des observations bornées ; aucun parcours de campagne ou inventaire de toutes les scènes n’en est déduit.

Ne jamais ajouter ce flag à Vercel. La route n’a aucun lien depuis les menus du jeu et porte une bannière permanente `QA visuelle synthétique · aucune sauvegarde/campagne` ainsi que `robots: noindex, nofollow`.
