## 1. Première mission guidée : Okavango

La première chasse sur Terre est **T-CT-01A « L'ivoire rouge »**, en version guidée. Elle apprend la boucle sans jamais arrêter le jeu par un écran de texte : chaque leçon passe par un **conseil de Saar** à la radio du vaisseau (il suit la chasse depuis l'orbite) ou par un **glyphe** du biomask.

| Étape | Ce que le joueur apprend | Comment |
| --- | --- | --- |
| 1. Registre | choisir un site et un contrat | l'archiviste montre l'Okavango ; seul ce contrat est disponible |
| 2. Orbite | zones de dépôt, fenêtres | deux zones ; Saar : « L'îlot est sûr. La plaine est proche, mais les lions y dorment. » |
| 3. Insertion | camouflage, discrétion d'arrivée | dépôt de nuit, aucun humain à proximité |
| 4. Repérage | mode Analyse, 7 marques | un porteur (blanc) et un garde (rouge) à côté : Saar : « Celui qui porte n'a pas d'arme. Celui qui garde, si. Regarde avant de frapper. » |
| 5. Traces | lire 3 traces | les traces brillent légèrement la première fois |
| 6. Écoute | radio, traduction | une radio s'allume tout près ; la traduction se fait sous les yeux du joueur |
| 7. Témoin | jauge d'envoi | un garde sort un téléphone ; le jeu ralentit 2 s la première fois ; Saar : « Il garde ton image. Brise l'objet. » |
| 8. Traque | voix imitée | le joueur enregistre une phrase et attire un garde loin du camp |
| 9. Boss | gabarit en 3 phases | Lisle ; le choix « achever / épargner » apparaît s'il se rend |
| 10. Trophée | camouflage coupé pendant le geste | Saar : « Pendant que tu prends, tu es visible. Assure-toi d'être seul. » |
| 11. Nettoyage | liste des traces, dissolvant | 2 corps et une caméra de chasse restent ; la liste s'ouvre seule |
| 12. Extraction | fenêtre | une seule fenêtre longue (6 min) pour cette mission |
| 13. Débrief | honneur, Indice, registre | chaque ligne du débrief s'éclaire une à une ; la première nouvelle humaine arrive à la chasse suivante |

**Règles de la mission guidée**
- Aucune infraction ne passe au tribunal pendant cette mission (avertissement seulement), **sauf** tuer un non-combattant.
- L'Indice ne peut pas dépasser 20 pendant cette mission.
- Le joueur peut couper les conseils de Saar dans les options.

## 2. Apprentissage progressif des systèmes

Les systèmes ne sont pas tous montrés dans la première mission. Ils s'ouvrent au fil des chasses, chacun avec un premier conseil :

| Système | Première apparition | Conseil |
| --- | --- | --- |
| Mécanique de site (marée, feu…) | chaque nouveau site | glyphe de la mécanique + une phrase de l'archiviste au briefing |
| Imitation sur radio | 2ᵉ chasse | Saar : « Une radio capturée parle à tous les leurs. » |
| Assommer un fuyard | premier fuyard désarmé | glyphe « assommer » |
| Duel sans masque | premier défi | Saar : « Il te défie. Tu peux refuser. » |
| Don au guerrier | premier humain épargné | glyphe du don |
| Hors saison | première chasse hors saison | archiviste : « La chaleur n'est pas là. Les proies non plus. » |
| Indice niveau 2 | premier passage | nouvelle humaine dédiée |
| ARGOS | premier passage au niveau 3 | scène T-SC-04 |
| Contrats de rang | rang Adjutant | l'Ancien les présente |
| Contrat Cleaner | rang Elite | l'Ancien |
| Ruche terrestre | premier événement | scène T-SC-13 |
| W-Y | première mission E3 | scène T-SC-12 |
| Coop | premier invité | aucun conseil : règles affichées au briefing |

## 3. Difficulté

| Réglage | Normal | Réalisme | Hardcore |
| --- | --- | --- | --- |
| Vue des humains | standard | + 25 % | + 25 % |
| Jauge d'envoi | 10 s (E1–E2) | 6 s | 4 s |
| Indice (gains) | × 1 | × 1,25 | × 1,5 |
| Marques du biomask | automatiques au scan | il faut maintenir le scan plus longtemps | pas de marque « incertain » : le joueur doit juger seul |
| Liste des traces au nettoyage | complète | seulement les corps | aucune |
| Fenêtres d'extraction | 3 | 2 | 1 |
| Mort | reprise au point de contrôle | idem | **définitive** |
| Autodestruction | évacué de justesse | évacué de justesse | mort |
| Capture par ARGOS | évasion + sauvetage à 15 min | évasion + sauvetage à 20 min | évasion seule |

**Réglages indépendants** (pour tous les modes) : aide à la visée, ralenti du premier témoin, conseils de Saar, affichage permanent de l'Indice.

## 4. Accessibilité

| Besoin | Réglage |
| --- | --- |
| Couleurs | les **7 marques** ont aussi une **forme** (cercle, losange, carré barré, triangle…) ; palettes pour les trois formes de daltonisme |
| Lecture | taille des sous-titres ; fond derrière les sous-titres ; vitesse de traduction des radios réglable |
| Son | tous les sons importants ont un **indicateur visuel** : pas d'humain, appel radio, jauge d'envoi, aboiement, fenêtre d'extraction |
| Ouïe | sous-titres des clics yautja (« clics graves »), des bruits d'environnement (« branche cassée à gauche ») |
| Mobilité | maintenir ou appuyer pour : scan, prélèvement, épargne, don ; aucune action ne demande de tapotements rapides (alternative à T-ANI-28) |
| Temps | option « fenêtres longues » (durée doublée) ; option « pause pendant l'écoute radio » |
| Mouvement à l'écran | réduire les secousses, le flou, les flashs (orages, éclairs, explosions) |
| Contenu sensible | réglage « moins de sang » ; le prélèvement de trophée est toujours coupé à l'image |
| Mode histoire | les proies humaines tirent moins juste ; l'Indice monte à moitié ; aucun tribunal sauf pour un non-combattant tué |

## 6. Codex terrestre

Le codex se remplit avec le jeu. Chaque entrée est **écrite du point de vue yautja** (glyphes, sous-titres).

| Catégorie | Entrées |
| --- | --- |
| **La Terre** | le monde qui répond ; les trois lois terrestres ; la chaleur ; les saisons rouges ; les Oomans et leurs armes |
| **Sites** | 20 entrées : chasse ancienne, faune, Oomans, évolution du site |
| **Oomans** | braconniers, milices, mercenaires, gardes, soldats, chasseurs, police, civils, pêcheurs, ouvriers (une entrée par archétype) |
| **Organisations** | ARGOS, OWLF, Weyland-Yutani |
| **Personnes** | Varga, Echeverría, Mensah, « Aiguille », Mira, Okonjo ; les 19 proies désignées ; les Honorés du joueur (entrées écrites par le jeu) |
| **Bêtes** | 30 espèces, dont les 12 grands animaux nommés |
| **Choses des Oomans** | téléphone, caméra, drone, radio, satellite, synthétique, dôme (vues par un Yautja : « petite boîte qui vole les images ») |
| **Nouvelles** | les nouvelles humaines écoutées (T-AN-36) |
| **Registre des Anciens** | les 20 chasses anciennes, une par marque retrouvée |
| **Le Patient** | ce qu'ARGOS sait du joueur, page par page |

**Exemple d'entrée (Choses des Oomans — Téléphone)** :
« Petite boîte de lumière que presque tous les Oomans portent. Elle vole l'image d'un chasseur et l'envoie à tous les autres en quelques souffles. Brise-la avant qu'elle ait fini. Les Anciens n'avaient pas à craindre cela. »
