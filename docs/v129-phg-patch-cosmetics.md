# PHG V129 — quatre matières originales issues d'une recherche des patches 2.08/2.19/2.40

Le paquet `PHG_V129_Four_Missing_Studies.zip` fournit **quatre études originales** en PNG et WebP 512², aperçus et atlas 1024². L'atlas est intégré au jeu (SHA-256 `4eac66e3dc679a207791f8d10d1ca75970a61db0c5c20b3547d52b91833d6b8f`) ; archive Drive (SHA-256 `a3ed68f538c64ec5105f2f157801bd85d35b5d63fa57332a4268d9dc3ee61732`). Ces images **ne sont pas les pixels UV/PBR du jeu PHG**, et aucune fidélité visuelle exacte 1:1 n'est certifiée.

- [2.08](https://forum.predator.illfonic.com/t/patch-notes-2-08/15883) : **Mottle Dread est une peau**, limitée à Scout/Hunter/Berserker dans PHG, pas une texture de dreadlocks.
- [2.19](https://forum.predator.illfonic.com/t/patch-notes-2-19/20975) : **Waves (Gator)** est un motif de peau, applicable aux sept classes documentées ; **Ogre** est une teinte de **biomask Alpha Predator**, et non une armure.
- [2.40](https://forum.predator.illfonic.com/t/patch-notes-2-40/28174) : les *predlocks Tank* se débloquent au niveau 150 dans le jeu original ; la matière V129 n'ajoute pas de nouvelle coiffure ou de géométrie.

Intégration : deux motifs peau et une matière dreadlocks passent par les canaux existants (studio, Homeworld et Canvas de chasse). La tuile Ogre est disponible dans le pack et la référence de masque, mais **jamais sélectionnable via `armorMaterialId`** tant que le module de biomask teintable n'est pas prêt. Les rangs PHG n'imposent pas de restrictions de rang à notre fan-game. La liste des 34 dossiers de fidélité non certifiés reste ouverte.
