# V41 — Celtic, Tracker et reprise Homeworld

Ce lot ajoute l’attente de Celtic, dans les deux orientations, à partir d’une planche générée avec OpenAI. Trois essais ont été réalisés ; les deux essais alpha sont rejetés pour bruit de détourage. La seule source retenue est le PNG magenta, conservé à l’identique. Quatre dessins nouveaux, deux clips orientés. Les mains, la lance, les lames, les contours et les transitions ont été contrôlés ; les appuis présentent encore une petite variation horizontale documentée.

Tracker reçoit deux correspondances de marche avant par lecture inverse de ses huit dessins de recul existants. Aucune image nouvelle n’est comptée pour lui. Les anciennes marches rejetées restent exclues.

Homeworld conserve en mémoire les IDs des quartiers réellement atteints dont la sauvegarde a échoué. La reprise est explicite, disponible au clavier et dans les dialogues manette, s’arrête au premier refus et recalcule chaque visite depuis les progrès acquittés. La file est isolée par campagne. Il faut réussir l’enregistrement avant de quitter la cité.

Le portable Windows est préparé en version 1.0.41 avec une racine de sortie dédiée, contrôles d’espace et empreintes en flux. La galerie peut ouvrir ses images locales en pleine résolution sans autoriser les pages HTML, SVG, scripts ou liens externes arbitraires. La preuve de l’exécutable et du ZIP est enregistrée après fabrication ; la préparation seule n’est pas une livraison PC.

Couverture réelle : 267 clips orientés, 11 combattants avec sprites animés sur 16 sélectionnables, 20 arènes jouables sur les 100 demandées, 552 sources dans l’atelier. Aucun moveset complet ni jeu commercial achevé n’est annoncé. Les autres chasseurs, arènes, véhicules pilotables, la jeunesse et le Berceau restent à poursuivre. L’accès aux discussions ChatGPT privées reste différé à la demande du propriétaire.

Les validations locales et publiques sont consignées dans `v41-local-verification.json` et `v41-delivery-verification.json`. La version source publiée reste distincte du commit de preuves.
