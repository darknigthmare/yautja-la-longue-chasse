124 captures natives Chrome sur fonds clair/sombre, corps120px, via le vrai préparateur et renderer d’atlas : toutes les frames résolues, aucun bord coupé, aucune erreur ni requête manquante. Maximum 20 pixels magenta fins sur une capture ; pas de fond opaque ni halo large observé. Clé couleur64 déclarée, originaux et SHA-256 conservés.

Limites : Human fighter is not present in PIT_FIGHTERS; no combat stats, hitboxes, attack timings or playable selection wired. Workshop review frames and review timing are not runtime coverage. Walking families remain rejected; no false alternating cycle or engine mirror. Jump page has four key poses, not complete rise/fall/landing phase clips. Forward pose-guide repair rejected for anatomy and facing drift. Existing V28 fan-made reference, not a certified1:1 official design. Original gameplay moves are adaptations.

Les rectangles et pivots sont explicites. Les ordres de phases ont été remis dans l’ordre réel du mouvement ; les durées décrivent uniquement la cadence de revue. Aucun squash, miroir ou frame interpolée ajouté. Les rejetées restent consultables comme sources, sans playback approuvé.
