# ART PIPELINE — AVP:R WOLF v0.7

Les six sprite-sheets vectorielles restent indépendantes du runtime : Wolf masqué, Wolf démasqué, Xénomorphe, Predalien, Facehugger et humain du magasin. Le standalone les embarque en data URI ; la version intégrée conserve les SVG séparés.

La v0.7 ne remplace pas artificiellement les assets par des frames officielles du film. Le travail visuel ajouté est procédural/runtime : télégraphe circulaire du Predalien, HUD de chaîne, débrief de chapitre, trauma dans le readout d'équipement et états d'alerte/IA.

Les captures Chromium v0.3 sont conservées comme référence historique. Aucun fichier `screenshots` existant n'est renommé en v0.7 afin d'éviter de faire passer une ancienne capture pour un rendu actuel.
