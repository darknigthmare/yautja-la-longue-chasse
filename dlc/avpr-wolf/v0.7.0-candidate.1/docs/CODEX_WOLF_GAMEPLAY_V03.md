# Codex gameplay — AVP:R WOLF v0.3

## Contrôles
- A/D ou flèches : déplacement horizontal.
- W/S : changement de plan 2D (1 à 3 profondeurs selon la zone).
- Espace : bond.
- E : interaction.
- F : attaque.
- 1–8 : arsenal.
- V : vision normale / thermique / xénomorphe tant que le biomask est porté.
- C : camouflage optique.
- T : seringue / analyse de piste dans les scènes de scan.
- H maintenu : Medicomp.
- R : Cleaner Fluid sur preuve proche.
- G : mine laser.
- M : route de nettoyage.

## Mécaniques dédiées
**Multi-plans.** Les zones utilisent plusieurs bandes de profondeur ; les xénomorphes peuvent changer de plan pour rejoindre Wolf.

**Camouflage.** Réduit fortement la distance de détection mais draine l'énergie.

**Centrale.** Les interférences thermiques perturbent la visée plasma et matérialisent la panne canonique.

**Cleaner Fluid.** Les scènes de nettoyage ne valident pas tant que toutes les traces obligatoires ne sont pas dissoutes.

**Plasma Pistol.** Inaccessible avant le magasin, construit après la bataille, puis perdu à l'étape de la cage d'ascenseur.

**Duel final.** Le Predalien ne peut pas être tué avant le seuil scénarisé ; le biomask est arraché, l'équipement est abandonné, puis la conclusion mortelle est verrouillée.

Clé locale dédiée : `tantalus.avpr.wolf.v03`. Elle ne modifie pas la sauvegarde principale de Tantalus.
