Intégration

Base hôte vérifiée : 73c0f6e8fe5e0a1301c6aa9becb5a67f0fb34aa9, SaveGame V9. L’installation par défaut ne modifie pas les sources publiques. Les deux patchs optionnels de développement refusent une restauration lorsque le fichier hôte a été modifié après installation.

Limites
