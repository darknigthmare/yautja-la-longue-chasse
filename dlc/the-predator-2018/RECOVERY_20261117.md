# The Predator (2018) — récupération dans la PR #146

Les 51 fichiers de la v0.5.0-candidate.1 sont restaurés octet pour octet à la racine de ce dossier. Les trois ZIP originaux disponibles (v0.2, v0.3, v0.5), leurs sommes SHA-256 et six fichiers isolés v0.4 sont conservés sous `history/`.

Les ZIP originaux v0.1 et v0.4 ne sont pas disponibles dans cette reprise. Aucun ZIP reconstruit n’est présenté comme l’original. Les rapports v0.5 dans `docs/` sont des rapports historiques, pas les résultats de ce job d’import.

Le job vérifie les SHA-256, les tailles, les CRC ZIP, les chemins, les 51 fichiers extraits et le total de 52 séquences / 183 micro-zones. Il n’exécute ni installateur ni moteur de jeu.

Le runtime, le standalone, les deux campagnes, les données, le codex, les captures originales, les tests, la passerelle Next.js et les installateurs sont conservés. Ce dépôt de sources n’active pas automatiquement le DLC dans HuntCanvas ou dans les cinq sauvegardes principales.

Les silhouettes procédurales de l’original ne sont pas des sprites bitmap dédiés validés 1:1. Les nouvelles productions doivent être isolées sous `production/` et accompagnées d’un statut honnête. Les Emissary, APC, hybrides supprimés et fins alternatives restent hors campagne cinéma.
