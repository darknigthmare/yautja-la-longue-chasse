# Migration v0.1 → v0.2

La v0.2 utilise une nouvelle clé de sauvegarde (`yautja.dlc.the-predator-2018.v2`) pour ne jamais écraser une progression v0.1. Les deux versions peuvent donc coexister.

Le modèle de campagne passe de 18/17 scènes à 26/26 scènes. Les identifiants E00–E26 deviennent le contrat de convergence pour une future fusion native dans le moteur principal.
